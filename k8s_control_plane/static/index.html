    Market data

    terminal and fast WebSocket fan-out tiers

    Terminal services

    MarketDataService objects with websocket.fastOnly=false. A terminal client connects once to /stream?streams=... or /ws and can SUBSCRIBE/UNSUBSCRIBE every configured symbol on that socket. The global service consumes every shard feed group.

    Fast services

    MarketDataService objects with websocket.fastOnly=true. Each connection is pinned to one symbol through /ws/<symbol>@<stream>, with exact sequenced delivery and no display conflation. Terminal /ws and /stream routes are disabled on these services.

    Read-only simulation from the CRD catalog and a synthetic observation. It does not contact the cluster or change desired state.

    Order systems

    user-ID sharded order-entry BFFs

    Order-system services

    Each user-ID shard has its own Deployment, Service and WebUI, and can target every engine shard and trading symbol. Open a shard's Demo order desk link to place and manage orders there; the manager does not proxy order entry. The links use each shard's Ingress host. On OrbStack, install k8s_control_plane/deploy/ingress-nginx.yaml and run scripts/ingress-frontdoor.sh start; otherwise port-forward the shard and open /demo/.

    New symbol

    Choose a supervisor shard for ongoing zero-impact placement; an empty containers shard is safe for its first symbol. Non-empty containers shards are disabled.

    Reserve empty shard

    Supervisor mode is the zero-impact default: adding a symbol updates the ConfigMap and starts a child process; no pod restarts. Containers mode adds a container and requires a one-voter-at-a-time pod roll.

    Drop shard

    This removes the shard, its deployments, routes and symbols that are not used elsewhere from the manager catalog. Every engine in the shard must already be stopped. Choose what happens to the Kubernetes storage before the operator prunes the workload.

    PVCs remain; re-create the shard later to recover its data.

    Update market-data image

    Market-data pods are stateless, so the operator rolls the Deployment with maxUnavailable: 0 and one surge pod. The target wire version must match every source shard; existing WebSocket connections drain through the preStop hook.

    New market-data service

    Create or edit a MarketDataService. Image and release are managed by the upgrade and rollback actions, not here.

    Scale market-data service

    Market-data pods are stateless. The HPA bounds must contain the replica count; set max = 0 to derive it from the replica count.

    Update order-system image

    Order-system shards are stateless, so the operator rolls every user-shard Deployment with maxUnavailable: 0 and one surge pod. The dropdown lists images cached on a node, currently running, or recorded in the catalog for this order system's repository.
