    New symbol

    Choose a supervisor shard for ongoing zero-impact placement; an empty containers shard is safe for its first symbol. Non-empty containers shards are disabled.

    Reserve empty shard

    Supervisor mode is the zero-impact default: adding a symbol updates the ConfigMap and starts a child process; no pod restarts. Containers mode adds a container and requires a one-voter-at-a-time pod roll.

    Drop shard

    This removes the shard, its deployments, routes and symbols that are not used elsewhere from the manager catalog. Every engine in the shard must already be stopped. Choose what happens to the Kubernetes storage before the operator prunes the workload.

    PVCs remain; re-create the shard later to recover its data.
